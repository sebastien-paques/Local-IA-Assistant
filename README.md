# Assistante IA locale

Projet personnel développé progressivement en parallèle de ma formation en cybersécurité et de mon apprentissage de Python.

## Objectif

Construire une assistante IA personnelle fonctionnant localement, pour accompagner mon apprentissage, consulter mes documents et intégrer progressivement mes propres outils Python et cyber.

Je souhaite comprendre son fonctionnement et garder le contrôle sur mes données, ses accès et les actions qu’elle peut effectuer.

## État actuel

- Ollama installé pour exécuter des modèles d’IA localement.
- Open WebUI installé comme interface de dialogue.

Le projet est au stade de la mise en place de l’environnement. Les fonctionnalités ci-dessous sont des objectifs de développement.

## Évolutions envisagées

- Recherche dans mes notes et documents personnels.
- Historique des conversations et mémoire contrôlable.
- Développement de modules Python pour des tâches précises.
- Intégration d’outils d’analyse de logs et d’aide en cybersécurité.
- Migration vers une machine plus puissante à terme.

## Accès et données

La priorité est un fonctionnement sans accès à Internet pendant l’utilisation.

Une éventuelle connexion future devra être explicitement activée par l’utilisateur, avec des permissions définies.

## Prochaine étape

Vérifier et documenter le fonctionnement de l’environnement installé, le modèle utilisé et les premiers tests.

## Contenu du dépôt

Ce dépôt accueillera la documentation technique, les configurations partageables et le code développé pour le projet.
